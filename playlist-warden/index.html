Playlist Warden for YouTube

Fair caps, cleanup & shuffle for shared playlists.

Chrome Local-first No account

What it does

Collaborative YouTube playlists fill up unevenly: some people add a lot, links rot, duplicates sneak in. Playlist Warden keeps shared playlists fair and clean with a single click on the „Run maintenance“ button right on the YouTube playlist page:

  • Fair caps — limit how many videos each contributor may keep on a shared playlist; the oldest surplus goes.
  • Cleanup (prune) — removes dead or unavailable videos (deleted/private/rejected) and duplicates across the whole playlist.
  • Content rules — optional filters for music category, age restriction, duration, title keywords, channels, and region blocks.
  • Shuffle — a real reshuffle after cleanup, so the final order is fresh.
  • Overview first — checks and dry-run plans before a single change is written; every action lands in a local audit log.

How it works

The extension integrates into the YouTube playlist page as a native-feeling button. Maintenance runs as a chain: checks → cap → prune → shuffle. Reads and writes use the official YouTube Data API v3 with your own Google sign-in (OAuth); writes only ever run on playlists you own. Contributor attribution is read from the collaborative playlist's avatar stack — the only place YouTube exposes it.

Privacy by design

  • Everything stays in your browser profile — playlists, rules, tokens, logs. There is no backend.
  • No analytics, no tracking, no ads, no third-party requests beyond googleapis.com.
  • Open source.
